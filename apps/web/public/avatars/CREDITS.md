# Avatar artwork

Generated with the DiceBear HTTP API and saved here as static files, so the app
makes no requests to DiceBear while running.

- `p01.svg` to `p12.svg` (people): "Avataaars" by Pablo Stanley, https://avataaars.com/,
  licensed "Free for personal and commercial use".
- `b01.svg` to `b08.svg` (shop assistants): "Bottts" by Pablo Stanley, https://bottts.com/,
  licensed "Free for personal and commercial use".

Each SVG keeps its original `<metadata>` block with the same attribution.
